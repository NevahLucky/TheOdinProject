## Commit System

My commit log will be maintained by following the 7 rules of good commit messages.

1. Seperate Subject & Body
2. Subject should be up to 50 characters
3. Subject should be written in the imperative mood
4. Subject should start with a capital letter
5. Subject should not end with punctuation
6. Body should wrap at 72 characters
7. Body should explain what & why
